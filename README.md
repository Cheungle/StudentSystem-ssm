## 核心功能
主要问题：超卖（lua），重复选课（lua+前端），大流量（线程池+redis+mq）
以redis中的库存和选课记录为准。
学生选课：前端发出选课请求-> 返回处理中，线程池接收-> redis中原子操作：判断是否已选，减库存，增加选课记录->
    选课结束，redis中存入结果，前端轮询-> 选课成功：发送mq消息异步写数据库

其中mq负责：写入选课记录

另外，定时任务1将redis库存数据持久化到mysql中（在选课期间，定时任务才开启）
定时任务2 凌晨将redis向mysql对齐

# 数据库

## redis
分级：一级普通缓存，二级持久化redis数据库
一级存放：计算量大的数据，例如count、多表查询，过期时间较短
二级存放：核心功能中不能丢失的数据，课程库存、已选课程信息，不设置过期时间
## mysql
计划排课表course_plan，上课时间表course_schedule，已成功选课表course_choose，
选课是否开放course_selection_permission
登录账号表admin（包括管理员、教师、学生），学生信息表student，教师信息表teacher
